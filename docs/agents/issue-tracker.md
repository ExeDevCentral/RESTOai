# Issue tracker: GitHub Issues

Issues and specs for RESTOia / KOBE live on GitHub: [ExeDevCentral/RESTOai](https://github.com/ExeDevCentral/RESTOai/issues).

## Conventions

- Issues live in GitHub Issues using GitHub CLI (`gh`) or the web interface.
- Local feature drafts and specs can optionally be staged under `.scratch/<feature-slug>/` before filing.
- Labels follow the canonical triage roles defined in `docs/agents/triage-labels.md`.

## When a skill says "publish to the issue tracker"

Create a new GitHub issue via `gh issue create --title "..." --body "..."` or provide the markdown content to post.

## When a skill says "fetch the relevant ticket"

Read the issue content via `gh issue view <issue-number>` or from the issue URL.
